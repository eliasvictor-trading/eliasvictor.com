# eliasvictor.com

Company website for Elias Victor, LLC.

## Stack

- Static HTML/CSS/JS
- Hosted on GitHub Pages
- Domain: eliasvictor.com

## Deployment

Push to main. GitHub Pages builds automatically.

## Files

- `index.html` — single-page site
- `logo.png` — site logo
- `favicon.ico`, `favicon-*.png`, `apple-touch-icon.png` — browser and search engine icons
